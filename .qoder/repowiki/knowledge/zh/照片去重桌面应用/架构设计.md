- **主进程 (Main)**：采用服务层架构 (`src/main/services`) 封装核心业务逻辑，包括文件扫描 (`scanner.service.ts`)、哈希计算 (`hash.service.ts`)、去重组队 (`dedup.service.ts`) 及设置管理。IPC 通信层 (`src/main/ipc/index.ts`) 负责桥接渲染进程与主进程服务，并处理窗口控制及进度事件推送。
- **预加载脚本 (Preload)**：通过 `contextBridge` 暴露安全的 API 接口 (`src/preload/index.ts`)，定义严格的类型契约，实现渲染进程与 Node.js/Electron 能力的隔离交互。
- **渲染进程 (Renderer)**：基于 React + TypeScript 构建 UI，使用 Zustand (`src/renderer/src/stores`) 进行全局状态管理（扫描状态、设置、去重结果）。UI 采用分步向导式设计 (`ImportStep`, `ScanningStep`, `CompareStep`, `ExecuteStep`)，并通过 Tailwind CSS 实现样式定制。
