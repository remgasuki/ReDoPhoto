# ReDoPhoto

Windows 桌面照片去重应用 —— 快速识别并清理重复/相似照片，支持精确匹配与感知相似检测。

## 功能特性

### 1. 文件夹导入

- 通过系统文件夹选择器导入目标目录
- 递归扫描所有子文件夹
- 支持图片格式：`.jpg` `.jpeg` `.png` `.gif` `.bmp` `.webp` `.tiff`
- 实时显示扫描进度与文件统计

### 2. 照片去重检测

提供三种检测模式：

| 模式 | 算法 | 说明 |
|------|------|------|
| **精确匹配** | SHA-256 | 基于文件内容哈希，仅检测完全相同的文件 |
| **相似检测** | pHash | 基于感知哈希 + DCT 变换，检测视觉相似的照片 |
| **组合模式** | SHA-256 + pHash | 同时使用两种方式，结果合并分组 |

- SHA-256 采用流式计算，分批处理，内存占用低
- pHash 支持自定义相似度阈值（1-15，值越大越宽松）
- pHash 使用 Union-Find 并查集进行高效分组

### 3. 可视化对比

- 左右分屏并排展示同一组中的重复/相似照片
- 显示文件名、文件大小、图片尺寸、哈希值等元信息
- 自动生成缩略图，无需等待全图加载
- 支持按文件大小排序

### 4. 手动选择保留策略

- **单组操作**：每组重复照片可独立选择保留左侧或右侧
- **批量操作**：一键「全部保留左侧」或「全部保留右侧」
- **灵活调整**：可随时清除所有选择，重新决策
- 选择状态实时高亮显示

### 5. 执行去重

两种输出模式：

- **Copy 模式**：将保留的文件复制到新文件夹，原文件夹保持不变
  - 自动镜像原始目录结构
  - 安全无风险，可随时对比
- **Delete 模式**：直接删除未被选中的重复文件
  - 操作不可撤销，需谨慎使用

### 6. 输出设置

- 自定义输出文件夹名称后缀（默认 `New`）
- 例如：原文件夹 `Photos` → 输出 `PhotosNew`
- 设置持久化保存，重启后自动恢复

## 项目结构

```
src/
├── main/                    # Electron 主进程
│   ├── index.ts             # 应用入口
│   ├── ipc/                 # IPC 通信处理
│   └── services/            # 核心服务
│       ├── scanner.service.ts   # 文件夹扫描
│       ├── hash.service.ts      # 哈希计算
│       ├── dedup.service.ts     # 去重处理
│       └── settings.service.ts  # 设置管理
├── preload/                 # 预加载脚本（安全桥接）
│   ├── index.ts             # contextBridge
│   └── index.d.ts           # 类型声明
└── renderer/                # 渲染进程（UI）
    └── src/
        ├── App.tsx          # 根组件（4步向导）
        ├── components/      # UI 组件
        ├── stores/          # Zustand 状态
        └── types/           # 共享类型
```

## 快速上手

1. 前往 [Releases](https://github.com/remgasuki/ReDoPhoto/releases) 页面下载最新版 `ReDoPhoto x.x.x.exe`
2. 双击运行，无需安装
3. 使用流程：

```
选择照片文件夹 → 等待扫描完成 → 逐组对比并选择保留项 → 执行去重
```

> Copy 模式下，保留的文件会复制到新文件夹（原名 + 后缀），原文件夹不变。
> Delete 模式下，未选中的文件会被直接删除，请谨慎操作。

## 开发者指南

以下说明面向希望从源码构建的开发者。

### 环境要求

- Node.js 18+
- npm

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

启动开发服务器，支持热更新。

### 构建

```bash
npm run build
```

### 打包绿色版 .exe

```bash
npm run build:win
```

产物位于 `dist/ReDoPhoto x.x.x.exe`，双击即可运行。
